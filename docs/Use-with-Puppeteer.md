# Puppeteer compatibility (deprecated)

Puppeteer compatibility is deprecated. It is not a product target, supported
client path, or release gate. This page is retained only so old links state
that boundary explicitly.

Use official Playwright Python through `connect_over_cdp`; see
[Use with Playwright](Use-with-Playwright.md). The qualified method slice and
known gaps are recorded in [SUMMARY](SUMMARY.md) and [TODO](TODO.md).
